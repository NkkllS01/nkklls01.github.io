Developed an AI decision pipeline combining ARIMA and LSTM demand forecasting with Chain-of-Thought (CoT) reasoning for replenishment recommendations. The project focuses on explainable AI for inventory decision support.

### Key Details

- Combined ARIMA and LSTM demand forecasting with Chain-of-Thought reasoning for replenishment recommendations
- Automated workflow orchestration and API triggers with n8n for end-to-end inventory decisions
- Built an interactive prototype to visualise forecast outputs, reasoning steps, and replenishment decisions
- Academic project (Aug 2025 – Feb 2026)

### Technologies

Python, ARIMA, LSTM, Chain-of-Thought reasoning, n8n, API orchestration

### Status
